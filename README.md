# Veritas Grants — Open Academic Scholarship Index

#### Video Demo: https://youtu.be/PRDEDEyaq_o

## Description
Veritas Grants is a high-performance, friction-free global scholarship discovery platform engineered to eliminate onboarding bottlenecks by removing login walls, registration requirements, and external file dependencies. Built entirely as a fully self-contained, lightning-fast single-file HTML5 web application, it integrates modern Tailwind CSS styling and vanilla JavaScript logic with an embedded comprehensive dataset to ensure instant responsiveness, high performance, and zero external file fetch latency. 

Students from all over the world can seamlessly search, filter, and discover fully-funded and partial academic scholarship opportunities in real time without creating accounts or dealing with paywalls. The platform features dynamic multi-attribute client-side DOM filtering based on search queries, target destination countries, specific degree levels, and exact funding coverage tiers. Furthermore, the user interface adheres strictly to high accessibility standards, featuring a professional high-contrast design system incorporating Academic Crimson and Success Emerald palettes to deliver an optimal user experience across desktop and mobile devices.

## Key Features
- **Zero-Friction Access:** No registration, login, account creation, or paywalls required whatsoever.
- **Real-Time Client-Side Search:** Instant DOM filtering by keywords, destination, degree level, and funding coverage.
- **Self-Contained Architecture:** Lightning-fast single-file implementation with embedded dataset and zero external file fetch dependencies.
- **WCAG Compliant UI:** High-contrast Academic Crimson and Success Emerald design system.

## Tech Stack
- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6)
- **Styling:** Tailwind CSS (Utility System via CDN)
- **Deployment:** GitHub Pages
