Veritas Grants — Open Academic Scholarship Index

A high-performance, friction-free scholarship discovery platform designed to eliminate onboarding bottlenecks by removing login/authentication walls. Built with a decoupled architecture fetching remote JSON data with real-time client-side multi-attribute filtering.

Live Demo
[Access Veritas Grants Live Portal](https://habeebch.github.io/veritas-grants/)

Key Features
Zero-Friction Access:** No registration, login, or paywalls required.
Real-Time Client-Side Search:** Instant DOM filtering by query, destination, degree level, and funding coverage.
Decoupled Architecture:** Modular UI driven asynchronously via external `scholarships.json`.
WCAG AAA Compliant UI:** High-contrast Academic Crimson (`#4C0519`) and Success Emerald (`#059669`) design system.

Tech Stack
Frontend: HTML5, Modern Vanilla JavaScript (ES6 Fetch API)
Styling: Tailwind CSS (Utility System)
Deployment: GitHub Pages
