# Veritas Grants — Open Academic Scholarship Index

#### Video Demo: https://youtu.be/PRDEDEyaq_o

#### Description:
Veritas Grants is a high-performance, friction-free scholarship discovery platform designed to eliminate onboarding bottlenecks by removing login/authentication walls and external file dependencies. Built as a fully self-contained single-file application featuring real-time client-side multi-attribute filtering.

- **Live Demo:** [Access Veritas Grants Live Portal](https://habeebch.github.io/veritas-grants/)
- **Author:** Habib Ur Rehman
- **GitHub & edX Username:** `habeebch`
- **Location:** Sialkot, Pakistan

## Key Features
- **Zero-Friction Access:** No registration, login, or paywalls required.
- **Real-Time Client-Side Search:** Instant DOM filtering by query, destination, degree level, and funding coverage.
- **Self-Contained Architecture:** Lightning-fast single-file implementation with embedded dataset and zero external file fetch dependencies.
- **WCAG AAA Compliant UI:** High-contrast Academic Crimson (`#4C0519`) and Success Emerald (`#059669`) design system.

## Tech Stack
- **Frontend:** HTML5, Modern Vanilla JavaScript (ES6)
- **Styling:** Tailwind CSS (Utility System via CDN)
- **Deployment:** GitHub Pages
